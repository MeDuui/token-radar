How implied value is computed

One function scores every row. The base multiple is not a constant: it is the median market-cap-to-TVL ratio of the live-token protocols in the same category, read from this very snapshot — a lending protocol is priced like lending protocols that already trade.

Age is the time since the protocol was first listed, the best record of how long it has run with no token; an unlisted age uses the median age of the ranked set. Breadth rewards protocols live on more than one chain. No protocol name is ever special-cased.
